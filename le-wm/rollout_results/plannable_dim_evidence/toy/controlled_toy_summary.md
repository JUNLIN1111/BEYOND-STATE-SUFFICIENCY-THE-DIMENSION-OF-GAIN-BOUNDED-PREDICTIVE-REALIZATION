# Controlled Transition Geometry Toy

This toy is a numerical counterpart to the false-shortcut concept figure.

- Physical coordinate dimension: 2
- Number of graph states: 82
- Geometry: crossroad plus one nearby parallel road
- Main/parallel road half-length: 16
- Vertical road half-length: 8
- Parallel road gap: 0.16
- Physical distance between selected nearby states: 0.1600
- Transition shortest-path distance between the same states: 33.0000
- Positive MDS rank: 5
- d50/d80/d90/d95/d99/d100: 2/3/4/4/5/5

Interpretation: the graph is drawn in 2D, but the transition distance is not the same object as 2D physical distance. Low-dimensional Euclidean embeddings can contract graph-far states into embedding-near false shortcuts.
